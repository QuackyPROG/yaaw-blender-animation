# Licensing, attribution and asset policy

This repository contains original YAAW Blender workflow code and instructions. No third-party media, branded artwork, fonts or motion templates are included in the scaffold. The distribution license has not yet been selected.

When incorporating third-party code, retain legally required license and copyright notices. Treat music/video/images/fonts separately from software licensing and record exact origin, permission, checksum and attribution obligations. Do not claim ownership of external assets. Never remove legally required notices.
