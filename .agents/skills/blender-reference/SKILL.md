# Motion reference analysis

Operate on a lawfully accessible local video. Extract metadata via ffprobe, contact sheets via FFmpeg, cut changes, brightness/contrast trends, apparent movement paths, object continuity and musical onset hints. Record confidence and source limitations. Do not describe video frames you couldn't view.

Output reports/reference_breakdown.json and a reviewer-readable contact sheet. Extract transferable principles into motion/storyboard design without copying exact compositions or branded art. Hypothesized easing is a hypothesis, not an observed project F-curve. Respect the approved project brief over stylistic examples.
## Non-negotiable operation rules

- Use the approved project brief and declarative frame/event specification; never invent missing institutional facts, copy or licenses.
- Produce native Blender bpy objects and editable .blend scene data, not a browser animation mislabeled as Blender.
- Verify using actual tests, rendered frames, reproducible commands and output paths.
- Technical PASS is distinct from aesthetic or listening HUMAN_REVIEW_REQUIRED.
- If required assets or executable APIs are unavailable, report BLOCKED; never silently substitute.
